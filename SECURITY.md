# Sicherheit

Dieses Projekt befindet sich in der Konzeptphase. Es gibt noch keine veröffentlichte App.

## Sicherheitslücken melden
Bitte melde Sicherheitsprobleme nicht in einem öffentlichen Issue. Nutze stattdessen die private Meldefunktion von GitHub unter „Security“ → „Report a vulnerability“ in diesem Repository. (Hinweis an den Betreiber: Diese Funktion muss in den Repository-Einstellungen aktiviert sein.)

## Grundsatz
Reale Ausweisdaten gehören nicht in Issues, Pull Requests oder Tests. Wenn du ein Problem beschreibst, verwende erfundene Beispieldaten.
