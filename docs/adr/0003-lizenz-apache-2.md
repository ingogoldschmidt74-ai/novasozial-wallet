# ADR 0003: Lizenz Apache-2.0
Status: entschieden (20.10.2026)
Entscheidung: Apache License 2.0.
Grund: freie, OSI-anerkannte Lizenz mit Patentklausel; unproblematisch für Play Store, App Store und F-Droid; keine Kosten.
Folge: Dritte dürfen den Code auch in Closed-Source-Produkten verwenden. Fremde Beiträge ab dann unter derselben Lizenz.
