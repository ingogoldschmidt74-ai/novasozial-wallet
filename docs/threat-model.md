# Threat Model (Startfassung)
- Zugriff Dritter bei entsperrtem Gerät
- Galerie-/Cloud-Sync von Aufnahmen
- Screenshots und Bildschirmaufnahmen
- Datenabfluss über das Netzwerk
- Schlüsselableitung und -ablage
- System-Backups und Debug-Builds
- Geräteverlust

Je Punkt später: Angriff, Wirkung, Gegenmaßnahme, Teststatus.
